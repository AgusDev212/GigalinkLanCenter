# 🎮 Gigalink LAN Center Games - Amanecidas Gamer +18

Plataforma web de filtro y verificación de mayoría de edad (+18) para acceder al grupo de WhatsApp oficial de las amanecidas de **GIGALINK LAN CENTER GAMES**.

---

## 🚀 Características

- **Filtro Estricto de Edad (+18)**: Cálculo en tiempo real de la edad a partir de la fecha de nacimiento y confirmación de casilla legal obligatoria.
- **Acceso Directo a WhatsApp**: Enlace oficial al grupo (`https://chat.whatsapp.com/L02j3Lgn66KIGIimfGZJzc?mode=gi_t`).
- **Aviso Destacado de Seguridad**:
  > **LA ENTRADA A LAS AMANECIDAS GAMER SERÁ CONTROLADA CON EL CARNET DE IDENTIDAD.**
- **Generador de Código QR**: Para escaneo directo desde computadoras hacia celulares.
- **Mascota Alien Gamer Oficial**: Diseñada para la identidad de Gigalink LAN Center Games.
- **Despliegue Automático en GitHub Pages**: Incluye GitHub Actions (`.github/workflows/deploy.yml`).

---

## 🛠️ Cómo publicar este proyecto en tu GitHub

Si quieres subir este repositorio a tu cuenta de GitHub, sigue estos sencillos pasos:

### 1. Crea un nuevo repositorio en GitHub
1. Entra a [github.com/new](https://github.com/new).
2. Asígnale un nombre (ej. `gigalink-lan-center` o `amanecidas-gamer`).
3. Elige que sea **Público** (para usar GitHub Pages gratis) y **no marques** inicializar con README ni `.gitignore`.
4. Haz clic en **Create repository**.

### 2. Conecta y sube el código desde tu terminal

```bash
# Si aún no has inicializado git en tu carpeta:
git init
git add .
git commit -m "Initial commit - Gigalink LAN Center Games +18 Filter"
git branch -M main

# Conecta con tu repositorio (reemplaza con tu usuario y repo):
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git

# Sube el código:
git push -u origin main
```

---

## 🌐 Cómo activar GitHub Pages (Web Pública Gratis)

Una vez subido el código a GitHub:

1. En tu repositorio de GitHub, ve a **Settings** (Configuración) > **Pages** (en el menú lateral izquierdo).
2. En **Build and deployment** > **Source**, selecciona:
   - **GitHub Actions**
3. ¡Listo! El workflow automático (`.github/workflows/deploy.yml`) compilará el proyecto y en 1-2 minutos tu web estará disponible en:
   `https://TU_USUARIO.github.io/TU_REPOSITORIO/`
